# Автоматические главы для русскоязычных подкастов

Исследовательский прототип для редактора подкаста. Из аудиозаписи он собирает черновик глав с таймкодами, названиями, темами и метками спикеров, а также описание для YouTube и файл глав в формате WebVTT. Редактор проверяет границы и текст перед публикацией.

[Открыть веб-интерфейс Chapterly](https://podcast-chapters-mvp.vercel.app) · [Запустить ноутбук в Colab](https://colab.research.google.com/github/majlychko/Timecoda-Chapterly/blob/main/podcast_chapters.ipynb) · [Посмотреть ноутбук на GitHub](podcast_chapters.ipynb) · [Таблицы и графики](results/README.md) · [Материалы для защиты](results/defense_slides.md)

## Веб-интерфейс Chapterly

В каталоге [`web/`](web/) находится адаптивный MVP на Next.js. Пользователь может выбрать источник выпуска — аудио или видеофайл, ссылку YouTube либо готовую расшифровку — настроить длительность и получить редактируемый список глав с блоком таймкодов для YouTube.

Текущая Vercel-версия использует лёгкую тематическую сегментацию без GPU. Полный исследовательский пайплайн распознавания речи, диаризации и генерации заголовков находится в [`source/`](source/) и запускается в Colab с GPU.

Локальный запуск интерфейса:

```sh
cd web
npm install
npm run dev
```

Для нового проекта Vercel укажите `web` в поле **Root Directory**. Команда production-сборки:

```sh
cd web
npm run build
```

## Что показал полный прогон

Команда обработала 6 выпусков «Радио-Т» общей длительностью 14,65 часа. На выпусках № 1029–1030 сравнили четыре распознавателя и выбрали Whisper large-v3-turbo с сегментацией TF-IDF по качеству границ. Настройки зафиксировали до проверки на выпусках № 1031–1034. В качестве эталона взяли таймкоды авторов. [Выборка](results/data.csv) · [Сравнение распознавателей](results/asr_selection_dev.csv)

| Метод разметки глав | Средний F1@30 на четырёх тестовых выпусках |
|---|---:|
| TF-IDF, выбран на настроечной выборке | 0,036 |
| Равномерная нарезка | 0,113 |
| Случайные границы, среднее по 20 повторам | 0,087 |
| USER2-base | 0,189 |
| Qwen3-Embedding | 0,255 |

При допуске ±30 секунд TF-IDF нашёл **1 из 31** эталонной внутренней границы и добавил 22 лишних. Средняя разница F1 с равномерной нарезкой составила −0,078, парный 95%-й бутстреп-интервал по выпускам — от −0,144 до −0,012. У Qwen3-Embedding оказался самый высокий тестовый результат. Для проверки его как нового основного метода нужна отдельная выборка. [Сводка метрик](results/test_summary.csv) · [Результаты по выпускам](results/test_per_episode.csv)

На 35 эталонных интервалах Qwen3-4B и заголовки по ключевым словам TF-IDF получили одинаковый hit@1 — 16 из 35. Все 27 заголовков на интервалах, найденных моделью, прошли автоматическую проверку формата и совпадения слов цитаты с расшифровкой. Редакторская оценка и хронометраж в студии ещё предстоят. [Оценки заголовков](results/title_proxy_summary.csv)

Обработка часа аудио выбранной цепочкой на прогретой Tesla T4 занимала в среднем **7,7 минуты**. При объёме 32,5 часовых выпуска в месяц и предположении, что редактор примет половину названий, модель затрат прогнозирует **45,5 минуты** работы вместо 75 на выпуск, или около **16 высвобожденных часов в месяц**. [Время этапов](results/timings.csv) · [Сценарии затрат](results/economics_scenarios.csv)

## Как повторить

1. Откройте ноутбук в Colab по ссылке выше и выберите среду Python с GPU T4. Для изменений сохраните копию в свой Google Drive.
2. В первой ячейке оставьте `RUN_PROFILE = "full"`, `DEVICE = "cuda"` и `RUN_STRESS_TEST = True`. Если нужен короткий пробный запуск, выберите `quick`: он использует по часу из двух настроечных и двух тестовых выпусков.
3. В меню **Среда выполнения** выберите **Выполнить все**. Ноутбук устанавливает пакеты и загружает материалы с сайтов «Радио-Т» и Hugging Face. Если рядом с ноутбуком нет каталога `source/`, он загрузит закреплённые версии пяти модулей из этого репозитория. Эталонные названия читаются со страниц выпусков. В сохранённом полном прогоне 24 ячейки кода заняли около 2 ч 36 мин от начала первой до конца последней.
4. Ссылка в последней ячейке скачивает `podcast_results_full.zip`. В личном архиве также будут расшифровки и тексты глав. Форма в разделе 11 позволяет отдельно обработать свою запись. Сохранённый прогон показывает демонстрацию на выпуске № 1031.
