# Chapterly: главы для русскоязычных подкастов

Исследовательский прототип создаёт из записи черновик глав с таймкодами, названиями, темами, метками спикеров и описанием для YouTube. Редактор проверяет материал перед публикацией. [Открыть актуальный ноутбук в Colab](https://colab.research.google.com/drive/1N-JYby1oIZNuQQfJ2PP8YooXih1Z5PDs) · [Открыть веб-интерфейс](https://podcast-chapters-mvp.vercel.app/).

## Актуальный полный прогон

В сохранённом прогоне обработаны шесть выпусков «Радио-Т» (14,65 часа): №1029–1030 для настройки и №1031–1034 для теста. Четыре ASR сравнивались при неизменных VAD и сегментаторе. GigaAM-v3, Whisper large-v3-turbo и Parakeet получили одинаковый F1@30 = 0,203 на настройке; GigaAM-v3 выбрана по заранее определённому порядку кандидатов. Для неё USER2-base показал лучший настроечный F1@30 = 0,333 и был зафиксирован до теста. Ручной транскрипции нет, поэтому выбор ASR по качеству границ косвенный.

| Метод сегментации | Macro F1@30 на четырёх тестовых выпусках |
|---|---:|
| USER2-base, выбран на настройке | 0,187 |
| Qwen3-Embedding | 0,153 |
| TF-IDF | 0,149 |
| Равномерная разбивка | 0,113 |
| Случайные границы, среднее 20 повторов | 0,087 |

У выбранного метода 5 совпавших, 18 ложных и 26 пропущенных границ; разница с равномерной разбивкой +0,074, её 95% бутстреп-интервал [−0,083; 0,188] включает ноль. Генеративные заголовки на авторских интервалах получили ROUGE-L F1 = 0,057; редакторская приемлемость не измерена. Тёплый RTF рабочего конвейера — 0,108. [Числовые таблицы](results/README.md) извлечены из сохранённых результатов ноутбука без повторного выполнения.

## Экономика: сценарий, а не наблюдавшаяся экономия

При предположениях 75 минут ручной работы и 50% принятия заголовков модель прогнозирует 41 минуту работы редактора после автоматизации: 34 минуты высвобождаются на выпуск, или 0,115 FTE при 32,5 выпусках в месяц. Денежный эффект зависит от сокращения расходов или дополнительного выпуска. Для подписки 230 ₽ за выпуск студии нужно монетизировать не менее **40,6%** высвобождённого времени, чтобы покрыть платёж 7 475 ₽ в месяц. При 50% прогнозный денежный эффект после подписки +1 732 ₽/мес. У разработчиков сценарный операционный порог — 11 постоянных студий; возврат начальных вложений за 24 месяца требует 29 постоянных студий. Эти значения требуют проверки редакторским хронометражем и пилотом.

## Запуск без изменения исходного кода

1. Откройте `podcast_chapters.ipynb` в Colab с GPU. Первая ячейка содержит параметры `RUN_PROFILE`, `DEVICE` и `DEMO_SOURCE`; исходный код модулей находится внутри ноутбука. Для полного эксперимента используйте `RUN_PROFILE = "full"`; для проверки запуска — `"quick"`.
2. Выполните ячейки по порядку. Ноутбук устанавливает зависимости и загружает открытые материалы и веса моделей. Доступность GPU и внешних источников зависит от Colab и сайтов поставщиков.
3. Для обработки **новой** записи укажите ссылку или загрузите файл в форме раздела 11 и нажмите «Обработать запись». В сохранённом прогоне форма отобразилась, но этот сценарий через неё не запускался.
4. Числовые результаты сохранённого полного прогона находятся в `results/`. Его повторный запуск занимает существенно больше времени, чем короткая проверка `quick`.

`source/` содержит извлечённые из текущего ноутбука модули и модульные тесты. `web/` — отдельный интерфейс с облегчённой сегментацией; он не выполняет полный GPU-конвейер. Исходные записи «Радио-Т» принадлежат их авторам и не включены в репозиторий.
