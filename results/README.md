Метрика F1@30 использует внутренние границы глав и допуск ±30 с. Сводная величина — среднее арифметическое по четырём тестовым выпускам. Пустое значение MAE означает, что при данном допуске нет совпавших границ. В `economic_sensitivity.csv` значение `inf` означает отсутствие окупаемости при данном сценарии. В `results_for_defense.json` финансовые пороги приведены как непрерывные значения, для целого числа студий их округляют вверх.

Снимок пакетов включает зависимости предустановленной среды Colab и локальный путь сборки Google. Для запуска используйте установочную ячейку ноутбука. Файл `timings.csv` различает повторное использование кэшированных результатов и новое вычисление.

В публичную сводку по названиям вошли средние оценки и число попаданий для каждого сочетания метода и типа интервала. Манифест содержит ссылки, количество глав и контрольные суммы разметки. Расшифровки, тексты и подробный разбор отдельных глав хранятся в полном архиве прогона. Сохранённые графики показывают сравнение методов, стресс-тест и денежные потоки.
