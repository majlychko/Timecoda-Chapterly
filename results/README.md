# Результаты сохранённого полного прогона

Таблицы извлечены из **сохранённых выводов ячеек актуального Colab**. При подготовке репозитория ноутбук и модели не запускались. Исходные аудиозаписи, полные расшифровки и тексты глав не публикуются.

Эксперимент: шесть выпусков «Радио-Т» общей длительностью 14,65 часа; настройка №1029–1030, тест №1031–1034. Основная связка GigaAM-v3 + USER2-base выбрана на настройке. На тесте macro F1@30 = 0,187, равномерная разбивка = 0,113; интервал разницы включает ноль.

- `asr_selection_dev.csv` — контролируемое сравнение четырёх ASR и отдельно лучшие связки;
- `dev_selection.csv` — зафиксированные параметры сегментации;
- `test_summary.csv`, `test_per_episode_selected.csv` — результаты теста;
- `title_proxy_summary.csv` — автоматическая оценка названий;
- `synthetic_stress_test.csv` — искусственное искажение текста;
- `production_rtf.csv` — время этапов;
- `unit_costs.csv`, `economic_sensitivity.csv`, `buyer_cash_scenarios.csv`, `buyer_break_even.json` — экономика покупателя;
- `internal_pnl.csv`, `internal_unit_economics.csv`, `internal_cash.csv` — сценарная экономика разработчиков.

Числа экономики используют допущения о времени и стоимости работы редактора, принятии названий и денежной реализации высвобождённых часов. Ручной оценки заголовков и редакторского хронометража нет. Статический отчёт не заменяет повторный запуск на новых данных.
