# Chapterly Web

Адаптивный MVP для подготовки глав и таймкодов подкаста. Интерфейс поддерживает выбор файла, ссылки YouTube или готовой расшифровки; текущий серверный API анализирует текст без GPU.

```sh
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Vercel

При импорте репозитория выберите `web` как **Root Directory**. Framework Preset определяется автоматически как Next.js.

Полная обработка аудио использует Python-модули из соседнего каталога `source/` и требует отдельного GPU-воркера.
